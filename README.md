# Cascos — Chácara de Nielt

Consulta do histórico de casqueamento **por brinco**, para o celular:
https://emilio9245-ux.github.io/cascos/

O endereço é público, então o conteúdo vai **cifrado** (AES-256-GCM, chave tirada da senha com
PBKDF2 de 210 mil voltas). Sem a senha, `index.html` é só um bloco de letras. A senha é a mesma da
Lista do Curral e **nunca** entra neste repositório.

Gerado por `CASCOS/historico/_motor/gerar_consulta.js` a cada rodada de cascos.
